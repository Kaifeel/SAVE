# Mutual Rental Reviews Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let lenders and borrowers submit one blind star-and-text review of each other within seven days of return, then show only published reviews and aggregates on public profiles and item details.

**Architecture:** Add one `reviews` table plus an immutable UTC `rentals.returned_at` event timestamp. A focused backend review package owns submission, visibility, policy, queries, and DTOs; existing rental, user, and item services consume those interfaces. The React rental flow submits reviews through `useRentals`, while the public-profile flow loads published reviews alongside the existing profile and items.

**Tech Stack:** Java 17, Spring Boot 3.3, Spring Data JPA, Jakarta Validation, Flyway/PostgreSQL, JUnit 5/MockMvc, React 19, Vite, Vitest, Testing Library, Tailwind CSS, Lucide React.

## Global Constraints

- Only lender and borrower participants may review each other after a rental reaches `RETURNED`.
- Rating is an integer from 1 through 5; trimmed text is required and limited to 500 characters.
- Each participant may submit once per rental; submitted reviews cannot be edited or deleted.
- Submission closes exactly at `returnedAt + 7 days`.
- Both reviews publish immediately when both exist; a lone review publishes when the seven-day deadline arrives.
- Hidden rating and text must not appear in participant responses, public lists, counts, or averages.
- All new event timestamps use `Instant`/`TIMESTAMPTZ` and all time-based tests use an injected `Clock`.
- Keep `7` in one Java constant with the exact maintenance comment `// 후기 작성 기한을 변경하려면 이 값을 수정하세요.`
- Do not add post comments, review editing/deletion, notifications, moderation, schedulers, or administrator settings.

public final class ReviewPolicy {
    // 후기 작성 기한을 변경하려면 이 값을 수정하세요.
    public static final int SUBMISSION_DEADLINE_DAYS = 7;

    private ReviewPolicy() {}

    public static Instant submissionDeadline(Instant returnedAt) {
        return returnedAt.plus(SUBMISSION_DEADLINE_DAYS, ChronoUnit.DAYS);
    }
}
