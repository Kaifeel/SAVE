# SAVE mobile app

This is the canonical Expo application for SAVE. It uses Expo Router with routes under `src/app`.

## Local setup

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env.local` and provide the public OAuth client IDs needed for the target platform.
3. Start Expo with `npm run start`.

Run `npm run test`, `npm run typecheck`, and `npm run lint` before committing mobile changes.
